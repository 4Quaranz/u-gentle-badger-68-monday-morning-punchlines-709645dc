A program that writes one joke about Monday mornings, at most 200 characters:

> Monday morning: my alarm filed a complaint, my coffee filed for divorce, and my calendar just laughed.

The line is 102 characters: Monday morning as a workplace revolt — the alarm, the coffee and the calendar all turn on the human at once.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
